# Izolowane reprodukcje

Uruchomienie: `node reproduce.mjs` w tym katalogu albo `node reproductions/reproduce.mjs` z katalogu raportu. Nie wymaga paczek npm. Oczekiwane wyjście opisuje reprodukcję starego problematycznego zachowania, **nie PASS naprawy**. Skrypt zapisuje `results.json` względem swojej lokalizacji; `run.log` zawiera log wykonania podczas audytu.

R01–R03 używają ręcznego portu logiki `createMoveGestureController` z [S10: `MoveObjectGizmo.tsx`](https://github.com/MateuszZelent/fullmag/blob/2a3c6becb9c7e111ae1497ec0cd9ac9576acba95/apps/control-room/src/modules/viewport-3d/MoveObjectGizmo.tsx), po usunięciu typów TS i warstwy renderowania. R04 jest modelem użycia `Number` w [S02: `geometryObjectPanelModel.ts`](https://github.com/MateuszZelent/fullmag/blob/2a3c6becb9c7e111ae1497ec0cd9ac9576acba95/apps/control-room/src/modules/inspector/panels/geometryObjectPanelModel.ts). R05 izoluje wybór draftu według key z [S01: `GeometryObjectPanel.tsx`](https://github.com/MateuszZelent/fullmag/blob/2a3c6becb9c7e111ae1497ec0cd9ac9576acba95/apps/control-room/src/modules/inspector/panels/GeometryObjectPanel.tsx). R06 odtwarza wyrażenie freshness z [S17: `useMeshDetailsModel.ts`](https://github.com/MateuszZelent/fullmag/blob/2a3c6becb9c7e111ae1497ec0cd9ac9576acba95/apps/control-room/src/modules/inspector/panels/mesh-details/useMeshDetailsModel.ts). R07 odtwarza fallback radiusSize z [S22: `viewport3dPrimitiveModel.ts`](https://github.com/MateuszZelent/fullmag/blob/2a3c6becb9c7e111ae1497ec0cd9ac9576acba95/apps/control-room/src/modules/viewport-3d/viewport3dPrimitiveModel.ts).

To nie uruchomienie produkcyjnych modułów, React, WebGL, backendu, meshera ani pełnego test suite. Szczególnie R05 nie jest testem montowania panelu, a R07 wymaga warunku braku bounds. Pliki służą do szybkiego pokazania mechanizmu i zaprojektowania właściwej regresji w repozytorium.

Pełny opis ograniczeń i macierz 50 proponowanych testów znajduje się w [dokumencie 08](../docs/08_TESTY_I_REPRODUKCJE.md).
